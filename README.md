
# Bug Tracking Application

## Project Overview
This project is a web application that allows software testers and developers to report, manage, and track software bugs.

## Features
- Submit bug reports with detailed information
- View and edit existing bug reports
- Assign severity levels to bugs
- Update bug statuses
- Filter bugs by severity and status
- Use AI to suggest bug severity levels

## Technologies
- Frontend: HTML, CSS, JavaScript
- Backend: To be determined
- Database: To be determined
- Project Management: Jira
- Version Control: Git and GitHub
